CalaPlayer 汉化 — 自定义翻译工具包
========================================

【这是什么】
  用它可以自己调整 CalaPlayer 的中文翻译：界面文字，以及角色名、动作、表情、
  背景音乐、环境音、音效、背景的显示名。

【推荐：图形界面（最简单）】
  1. 双击运行   打开汉化工具.bat   （需要电脑装了 Python 3）
  2. 会自动打开浏览器。顶部分页：界面文字 / 角色名 / 动作 / 表情 /
     背景音乐 / 环境音 / 音效 / 背景。每页左边英文、右边填中文，
     可以搜索、只看未翻译；界面文字页还能看每条文字出现在哪。
  3. 改完点【保存】，再点【打包并安装到游戏】（打包前先关游戏），
     等日志显示成功，启动游戏即为新翻译。

【或者：手动改文件】
  1. 用记事本打开  translations.json
  2. 里面是一行行   "英文" : "中文",
     把冒号右边引号里的中文，改成你想要的文字
     （只改中文那一半，别动英文那半边和标点、逗号）
  3. 保存。
  4. 先【完全关闭游戏】，然后双击运行   重新生成并安装.bat
  5. 等它显示  [OK] 完成  跑完，启动游戏就是你的新翻译了。

【想新增词条】
  照格式加一行即可，例如：
     "New Scenario" : "新建剧本",
  左边英文必须和游戏里的原文【完全一致】（区分大小写、空格、标点）。
  游戏里全部可翻译英文原文见： 所有可翻译文本.json（图形界面里也会直接列出）

【各类名称（角色名、动作、表情、音乐、音效、背景）】
  每类一个文件，格式都是  "游戏里的英文名" : "中文",
     resname_map.json     角色名
     anim_map.json        动作
     morph_map.json       表情
     bgm_map.json         背景音乐
     ambient_map.json     环境音
     sound_map.json       音效
     background_map.json  背景
  它们都只改「显示」：剧本里存的、游戏加载用的仍是英文名，所以旧剧本照常能用，
  删掉汉化后剧本也不受影响。中文留空 = 保持英文。
  注意：动作、表情的中文名不能重复（[+] 添加菜单里选中中文后，要换回英文交给游戏）。
  背景名参考了官方剧情（BWIKI 剧情故事页）里各背景出现的场景。
  改完同样跑一次打包即可生效。

【还原成英文】
  删掉游戏目录  CalaPlayer\Content\Paks\  下这 3 个文件即可：
     CalaPlayer-Windows_P.utoc
     CalaPlayer-Windows_P.ucas
     CalaPlayer-Windows_P.pak

【注意】
  - 运行脚本前一定要先关掉游戏（否则文件被占用，装不进去）。
  - 别移动 CalaPlayer 整个文件夹的结构（脚本靠相对路径找工具）。
  - 脚本会自动重新打包并安装，改完翻译跑一次即可。
