适用于 **CalaPlayer v0.1.0.134**（旧版播放器）的简体中文汉化维护版。

> 版本号格式：`PV<适用的播放器版本>-v<汉化版本>`。使用 v0.1.1.140 的请下载 [PV0.1.1.140-v1.4](https://github.com/Xenon-XG/CalaPlayer_Translations/releases/tag/PV0.1.1.140-v1.4)。

## PV0.1.0.134-v1.3.1 更新（相对 v1.3）
- 补上 3 个此前漏译的表情：左眼·闭3、右眼·闭3、嘴3（名字带数字后缀，之前没收录到）。
- 其余内容与 v1.3 相同：界面文字，以及角色名、动作、表情、背景音乐、环境音、音效、背景的中文显示。名字只改「显示」，剧本里存的仍是英文原名。

## 安装（即插即用）
下载下方的 zip，解压后把其中 3 个 `CalaPlayer-Windows_P.*` 文件复制到游戏目录的 `CalaPlayer\Content\Paks\`，启动游戏即为中文。

## 卸载 / 还原英文
删除那 3 个 `CalaPlayer-Windows_P.*` 文件即可。
