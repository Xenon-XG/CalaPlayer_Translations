适用于 **CalaPlayer v0.1.1.140**（《卡拉彼丘 / Strinova》剧情演出编辑器）的简体中文汉化。

> 版本号格式：`PV<适用的播放器版本>-v<汉化版本>`。请下载与你的播放器版本一致的包；v0.1.0.134 请使用 v1.3。

## PV0.1.1.140-v1.4 更新
- **适配 CalaPlayer v0.1.1.140**，原有的界面文字和各类名称汉化全部移植到新版。
- **新版新增界面文字已汉化**：清除旧表情、色调、饱和度、修改背景、复制（时间轴块）、确定、警告，以及打开高版本剧本时的提示。
- **新角色**：千代、汐、蕾欧娜、玛拉、诺诺、假人。
- **新动作、新表情**：蕾欧娜、玛拉的动作和表情均已汉化；并补上了 3 个此前漏译的表情（左眼·闭3、右眼·闭3、嘴3）。
- **音效下拉新增的环境音条目**、新增的纯色背景（纯黑、纯白）已汉化。
- 名字依旧只改「显示」，剧本里存的仍是英文原名，旧剧本照常可用。

## 安装（即插即用）
下载下方的 zip，解压后把其中 3 个 `CalaPlayer-Windows_P.*` 文件复制到游戏目录：

```
CalaPlayer\Content\Paks\
```

启动游戏即为中文。首次启动可能因编译着色器短暂“无响应”，稍等即可。

## 卸载 / 还原英文
删除那 3 个 `CalaPlayer-Windows_P.*` 文件即可。

## 说明
- 不改动任何原始游戏文件，只新增一个高优先级补丁包（`_P`），安全、可逆。
- 想自己改词：界面文字见仓库 `translations.json`，各类名称见 `*_map.json`，也可以用 `tools/打开汉化工具.bat` 在浏览器里改并一键打包。
